Start with the store you need to connect. The [App Store guide](/docs/connect-app-store/) and [Google Play guide](/docs/connect-google-play/) explain the provider permissions, credentials, review history, and reply limits before you open the connection form.

ReviewInbox is open source. Read the [source code on GitHub](https://github.com/bibliocards/reviewinbox) or compare the [App Store and Google Play workflows](/docs/manage-both-stores/).

Once reviews are imported, [Review analysis](/docs/review-analysis/) helps teams see recurring topics, reported severity, and trends by period, store, and app version. Jev classifies imported reviews; Luna proposes missing topic labels for human approval.
